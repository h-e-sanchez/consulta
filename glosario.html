glosario

Los términos que aparecen en consulta, en lenguaje llano. Nada de esto hace falta saberlo de antemano: la herramienta funciona igual.

notaCada término del sitio enlaza acá; podés volver con el botón «atrás» del navegador. Los ejemplos usan la relación datos, que es como consulta llama a la tabla cargada.

Formatos y archivos

CSV
Comma-Separated Values. Una tabla guardada como texto plano: una fila por línea, columnas separadas por comas. Lo que exporta cualquier planilla. Fácil de leer, pero sin tipos ni compresión.
Parquet
Un formato de archivo columnar y comprimido, estándar en analítica. Guarda cada columna junta (no cada fila), así que leer «solo tres columnas de un archivo enorme» es rápido y barato. Trae los tipos de dato incorporados.
Excel / XLSX · hoja de cálculo
Un libro de Excel (.xlsx) u ODS (.ods) puede tener varias hojas. consulta lee el libro en el navegador, te deja elegir qué hoja importar, y la convierte a una tabla. Cambiar de hoja no vuelve a pedir el archivo. La primera fila de la hoja se toma como los nombres de columna.
relación / tabla
El conjunto de filas y columnas cargado. En consulta siempre se llama datos: toda consulta SQL lee de ahí.
esquema
La lista de columnas de una relación con su tipo. Se infiere automáticamente al cargar.
tipo de dato
BIGINT y DOUBLE: números (entero y decimal). VARCHAR: texto. DATE: fecha. TIMESTAMP: fecha y hora. BOOLEAN: verdadero/falso.
nulo
Ausencia de valor en una celda — distinto de cero o de texto vacío. En SQL se compara con IS NULL, no con = NULL.
dimensión vs. medida
Una dimensión es una columna por la que agrupas o filtras (categoría, región, mes). Una medida es un número que sumas o promedias (monto, cantidad). El gráfico usa una de cada una.

El motor

SQL
Structured Query Language. El lenguaje estándar para consultar datos tabulares. Una consulta describe qué querés (columnas, filtros, agrupaciones) y el motor resuelve el cómo.
dialecto
Cada motor SQL tiene variaciones. consulta usa el dialecto de DuckDB, que agrega comodidades como SUMMARIZE, PIVOT y date_trunc.
DuckDB / DuckDB-WASM
DuckDB es una base de datos analítica que corre embebida (sin servidor). DuckDB-WASM es su versión compilada a WebAssembly: el mismo motor, corriendo dentro del navegador.
WebAssembly (WASM)
Un formato binario que el navegador ejecuta casi a velocidad nativa. Permite llevar software escrito en C++ o Rust —como DuckDB— a una página web.
Web Worker
Un hilo de ejecución aparte del de la página. El motor SQL corre ahí para que una consulta pesada no congele la interfaz.
en el cliente / client-side
Todo el procesamiento ocurre en tu equipo, en el navegador. El archivo que cargás no se sube a ningún servidor. «Sin backend» dice lo mismo: no hay un servidor haciendo el trabajo.
OLAP
Online Analytical Processing: consultas de análisis (agregar, agrupar, cruzar muchas filas) en oposición a las de un sistema transaccional (insertar/actualizar registros de a uno).
runtime vendorizado / offline
El motor de DuckDB (el bundle de código y los binarios WASM) está guardado dentro del propio sitio, en vendor/duckdb/, en vez de bajarse de un CDN. Así consulta funciona sin conexión a internet, también la primera vez que se abre.

Consultas

CTE — WITH … AS (…)
Common Table Expression. Un resultado intermedio con nombre, definido al inicio de la consulta, que el resto puede usar como si fuera una tabla. Sirve para partir una consulta larga en pasos legibles. La pestaña Combinar arma estas cadenas.
función de ventana
Un cálculo sobre un conjunto de filas «vecinas» sin colapsarlas en una sola (OVER (…)). Ejemplos: media móvil, acumulado, ranking, variación contra la fila anterior.
SUMMARIZE
Comando de DuckDB que perfila toda la relación de una pasada: por columna devuelve tipo, rango, cardinalidad y estadística. Es la base de la pestaña Perfilado.
PIVOT
Convierte valores de una columna en columnas nuevas. De «mes, segmento, total» (largo) a «mes, A, B, C, …» (ancho).
date_trunc
Recorta una fecha a una unidad: date_trunc('month', fecha) lleva toda fecha al primer día de su mes. Es como se agrupa una serie por periodo.
media móvil
El promedio de los últimos N periodos, recalculado en cada punto. Suaviza el ruido de una serie para ver la tendencia.

Estadística del perfilado

cardinalidad / valores distintos
Cuántos valores diferentes tiene una columna. Alta (cerca del total de filas) sugiere un identificador; baja sugiere una categoría. El perfilado la estima de forma aproximada para que sea rápida.
cuantil / percentil
El percentil p es el valor por debajo del cual queda el p % de los datos. El p50 (mediana) parte los datos a la mitad; el p95 deja el 5 % más alto por encima.
mediana (p50)
El valor del medio. A diferencia del promedio, no se mueve si hay unos pocos valores extremos — por eso conviene mirar las dos.
media / promedio
La suma de los valores dividida por la cantidad.
desviación estándar
Cuánto se aleja un valor típico de la media. Chica = datos concentrados; grande = dispersos.
correlación (Pearson)
Un número entre −1 y 1 que mide qué tan bien dos columnas numéricas se mueven juntas de forma lineal. 1: cuando una sube, la otra sube en proporción constante; −1: cuando una sube, la otra baja; 0: sin relación lineal (puede haber otra no lineal). El perfilado muestra la matriz de todas las parejas.
valor atípico (outlier)
Un valor muy alejado del resto. Señal: un p95 mucho menor que el máximo, o una media bastante mayor que la mediana.

El generador

relación sintética
Datos inventados por la propia página para probar la herramienta sin traer un archivo. No provienen de ninguna fuente real.
PRNG / semilla
El generador usa un generador pseudoaleatorio determinista: la misma semilla produce exactamente la misma relación, siempre. Cambiá la semilla para otra muestra con la misma estructura.
panel
Datos con dos ejes: varias entidades observadas repetidamente a lo largo del tiempo (entidad × fecha). También se le dice «datos longitudinales».
serie de tiempo
Una secuencia de valores ordenados por fecha. Casi todo el análisis de consulta gira alrededor de esto.
